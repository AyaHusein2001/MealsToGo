# MealsToGo 🍽️

MealsToGo is a mobile restaurant application built with **React Native** that allows users to browse available meals, manage their favorite dishes, and authenticate using **Firebase**.  
The app focuses on clean UI, smooth navigation, and real-world mobile app features such as authentication and user profiles.

---

## ✨ Features

- Browse restaurant meals
- User authentication (Sign Up / Sign In) using Firebase
- User profile with profile picture
- Add and remove favorite meals
- Persistent user data using Firebase
- Clean and intuitive mobile UI
- Search and filter meals depending on country

---

## 🛠️ Tech Stack

- **React Native**
- **Firebase**
  - Authentication
  - Firestore / Database
  - Storage (for profile pictures)
- JavaScript (ES6+)

## 🚀 Getting Started

### Prerequisites
- Node.js
- npm or yarn
- Expo CLI or React Native environment
- Firebase project

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/AyaHusein2001/MealsToGo.git
   ````

2. Install dependencies:

   ```bash
   npm install
   ```

3. Add your Firebase configuration:

   * Create a Firebase project
   * Enable Authentication and Firestore
   * Update `firebase.js` with your credentials

4. Run the app:

   ```bash
   npm start
   ```
